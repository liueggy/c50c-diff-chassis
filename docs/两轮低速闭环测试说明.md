# 两轮低速闭环测试

烧入 `Diff_Car_ClosedLoop_Test.hex`，目标为两轮同时前进80 mm/s。架空驱动轮后测试。

使用12 V电源，门槛10 V仅用于短时台架测试，不是电池保护设定。等待5秒，目标速度用1秒升到80 mm/s，保持3秒，1秒降到零，上电约10秒停止，复位才重试。PWM频率10 kHz，上限50%，只允许前进输出；采用原增量PI算法300/300，测试开始重置PI，不使用Flash旧增益。

已确认：A左轮、B右轮；两路原测试方向均倒退，因此正常电机符号均改为-1。编码器手转前进反馈为正，保留A=1、B=-1；减速比28、500线、四倍频每轮56000计数，轮径0.2032 m、轮距0.55 m。

OLED：CL TEST WAIT / RUN / DONE；BLOCKED为供电、使能、软件停止或硬件检查；CL ENCODER ERR为反馈小于-20 mm/s、超过300 mm/s或无效数值；CL STALL STOP为目标大于30 mm/s、PWM至少25%而反馈小于2 mm/s持续1秒。任一故障锁存停止两轮，恢复条件后仍需复位。DONE仅表示定时时间结束。

DL、DR每行左侧目标速度，右侧反馈速度，单位mm/s。RUN期间两侧应为正，稳态目标+00080，反馈应趋近80；电机实际转速需现场观察。关闭使能应停止两轮。停止时输出归零并清除PI；普通Diff_Car的配置门控保持关闭，单轮测试版保持原诊断方向。
