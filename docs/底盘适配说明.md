# C50C两轮差速底盘适配说明

当前开发分支 `Eggy`，日常Keil目标 `Diff_Car`，基线保留在 `main`。集中配置入口为 `CarType/Inc/chassis_config.h`；本说明按2026-10-14当前代码及已记录的实机结果更新。

## 硬件与参数

| 项目 | 当前值与依据 |
|---|---|
| 主控 | C50C V4.3，STM32F407VET6 |
| 底盘 | 两主动轮、两从动全向轮 |
| 轮距 | 0.55 m，用户实测主动轮中心距550 mm |
| 主动轮名义直径 | 0.2032 m，旧手册8寸；有效周长仍待标定 |
| 减速比 / 编码器 | 28 / 500线，来自旧底盘手册；用户确认电机与编码器沿用同一辆车 |
| 原始计数 | 四倍频：500 × 28 × 4 = 56000 / 轮圈；当前程序不做旧程序的除8处理 |
| 默认速度PI | KP=300、KI=300；现有Flash参数可能覆盖默认值 |
| 电机方向符号 | A=-1、B=-1，依据两路原开环测试均为后退 |
| 编码器符号 | A=1、B=-1，手转前进时屏幕反馈为正，后退为负 |
| 供电门控 | 当前12 V供电；9.5 V停机/低压告警，10.5 V清除低压告警 |

`CHASSIS_CONFIG_CONFIRMED=1` 已启用正式输出；无效几何参数或关闭确认仍禁止输出。固定type=0选择A/B差速配置，绕过车型电位器；其他车型目标保持原配置。关闭 `CHASSIS_ENABLED` 可使用原厂差速配置。

## 控制板信号与实机对应

| 通道 | PWM | 方向输入 | 编码器 |
|---|---|---|---|
| A，左轮 | PC9 / TIM8_CH4 | PB13 / PB12 | PA15 / PB3，TIM2 |
| B，右轮 | PC8 / TIM8_CH3 | PC0 / PE15 | PA6 / PA7，TIM3 |

TIM8为10 kHz PWM，周期16800计数。驱动采用PWM/方向接口，不移植F103 GPIO，也不使用D50A RS485管理任务。WSDC2412D资料支持该控制方式；具体驱动型号与连接器针序以实物和原理图为准。

已验证左右电机、编码器及方向对应。旧底板编码器接口为5 V，C50C插座为3.3 V；更换外设或线束时仍需核对电气兼容性。手册电流额定值不等同于本车实测持续能力。

## 正常运动与串口

普通 `Diff_Car` 取消上电自动前进和原厂主动深度自检。串口接收前约10秒被忽略，正常运动入口仍有约12.3秒的启动等待。

运动只使用USART3，115200、8N1，接收11字节速度指令；USART1只保留下载与状态回传，先零帧解锁；线速度范围±700 mm/s、角速度±1000 mrad/s。100 Hz任务解析并计算两轮目标，速度PI控制电机；连续合法指令之间须小于500 ms，超时或解析错误清零命令并要求零帧重解锁。

20 Hz串口回传自定义22字节状态帧，含轮速、电压与IMU原始数值；不是原厂24字节ROS回传帧。完整字段与状态见 [串口控制说明](串口控制说明.md)。现有工具为普通Python串口工具，ROS 2桥接、里程计和TF由上位机负责人在其仓库实现；本仓库交付协议与参考工具。

实际配置、启动等待、使能、9.5～28 V电压、软件停止、错误和硬件版本均参与解析器门控。失能恢复时丢弃旧帧，重新零帧解锁；超时/错误/零速度当周期清PWM、目标/平滑速度和PI，异常不经过普通平滑减速。串口超时保护来自独立解析模块，不依赖原厂SecurityLevel。

## 显示与灯效

OLED沿用原配六针接口：GND、3V3、PD7(SCL)、PD4(SDA)、PE1(RST)、PE0(DC)。普通目标使用两页中文界面：概览页显示状态、电压、串口与配置；动态页显示两轮目标/实测、占空比与角速度。长按PC5用户按键翻页。诊断目标保留专用测试状态显示。

RGB由 `led_task` 控制红、橙、黄、绿、青、蓝、紫逐色呼吸，每色约4秒，整轮约28秒；呼吸灯不表示电机已允许运动。

## 验证状态与开发入口

已由用户确认：两侧单轮开环可转；编码器左右对应及正负正确；两轮80 mm/s闭环反馈跟随目标；定时结束反馈归零；运行中使能OFF可停止。后续记录中的100%占空比实测约950 mm/s仅为该条件下的观察值，不作为准确标定或安全速度上限。

待实车验证：串口控制/异常停车/恢复重解锁及网页操作超时；待双方联调：上位机按接口协议适配，真实轮速与里程计标定。

- [诊断测试入口](diagnostics/README.md)：保留PC8、单轮和两轮闭环独立目标。
- `python tests/test_chassis_profile.py`：配置、差速运动学、输出门控与诊断行为。
- `python tests/test_chassis_uart_control.py`：实际C解析器的帧校验、超时和重解锁。
- `python tests/test_chassis_serial_safety.py`：实际解析器、门控、停机输出和独占ISR集成。
- `python tests/test_chassis_telemetry.py`：22字节黄金帧、状态及停机IMU反馈。
- `python tests/test_chassis_web.py`：网页操作/回执超时、非法输入与恢复不重放。
- 编译使用Keil ARM Compiler 5.06 update 5；编译成功不代替实车验证，不自动烧录。
