# Eggy 两轮差速底盘初步适配

目标：C50C V4.3 / STM32F407VET6，四轮两驱底盘（两主动轮、两从动全向轮），现有双通道PWM驱动板，C50C原配六针OLED。基于 main 的 7961a36，仅在 Eggy 分支开发。

## 当前配置与适用边界

在 Keil 选择 `Diff_Car`。`CarType/Inc/eggy_chassis_config.h` 是集中配置入口。

| 参数 | 当前值 | 依据 |
|---|---|---|
| 主动轮名义直径 | 0.2032 m | 旧安装手册标称8寸；有效周长待实测 |
| 减速比 | 28 | 用户本轮确认先采用28 |
| 编码器线数 | 500 | 用户本轮确认先采用500 |
| 每轮原始计数 | 56000 | 500 × 28 × 4；新程序不再除以8 |
| 主动轮中心距 | 0，待测 | 不将旧遥控系数0.275当成已确认尺寸 |
| 默认速度PI | 300 / 300 | 保留C50C默认值，尚未实机调参；旧程序4/4不可直接搬入 |
| 输出与编码器方向 | C50C默认方向 | 已提供各轮独立符号宏；实际接线待核对 |

自定义配置绕过TYPE电位器，内部固定type=0以使用A/B两轮控制；其他编译目标继续使用原厂配置。若关闭 `EGGY_CHASSIS_ENABLED`，保留原厂差速档位，并为原本未初始化的ADC档位增加TYPE 0回退。

轮距未填写或 `EGGY_CONFIG_CONFIRMED=0` 时，软件停机检查和最终PWM输出入口同时禁止电机输出，OLED首页显示 `CFG REQUIRED`。内部使用1 m计算占位宽度避免除零，这不是实物尺寸；此时上报的车体角速度不可用于里程计。手动转轮的反馈按名义轮径换算，尚未标定。

这套配置取消上电自动前进自检，也不运行原厂四通道主动深度自检。正常命令仍沿用原来的启动等待约12.3秒。填好实测轮距并完成电气核对后，将 `EGGY_CONFIG_CONFIRMED` 改为1重新编译，再按低速单轮步骤验证方向。

## 驱动板接线参考

本适配使用PWM/方向接口；没有移植旧F103的GPIO分配，也不使用D50A RS485任务。若实际板型为旧资料中的WSDC2412D，接线按该驱动手册核对：

| C50C逻辑通道 | PWM | 方向1 | 方向2 | 编码器A/B相 |
|---|---|---|---|---|
| A：左主动轮 | PC9 / TIM8_CH4 | PB13 | PB12 | PA15 / PB3 |
| B：右主动轮 | PC8 / TIM8_CH3 | PC0 | PE15 | PA6 / PA7 |

以源码定义的信号网名为准核对连接器，原厂资源表的PWM字母标注曾出现不一致。C50C控制信号接驱动板的PWM、INA、INB；驱动板功率端连接电池和电机。控制侧VCC须与逻辑信号幅值匹配。保持现有10 kHz PWM，不将单通道12 A的手册额定条件当成实测能力。

旧底板编码器供电为5 V，而C50C编码器插座供电为3.3 V；必须先确认编码器供电范围和输出电平，不能直接套接旧线束。首次接线还需分别验证“左轮/右轮、PWM通道、编码器通道、前进符号”的对应关系。

## OLED与保留功能

沿用C50C V4.3原配六针OLED及原驱动。该版本映射为GND、3V3、PD7(SCL)、PD4(SDA)、PE1(RST)、PE0(DC)。不需要搬入F103 OLED驱动。

保留FreeRTOS、ICM20948、串口/CAN状态反馈、原有速度PI与参数保存。OLED保留前三页，隐藏无关传感器和D50A页面；首页显示配置状态及左右轮目标/反馈。

本次未修改原厂 `SecurityLevel=1`，命令超时清零默认仍未启用。旧串口FF FE协议及CAN 0x121协议不能直接控制新程序。既有Flash参数可能覆盖默认PI，调参前应读取确认。

## 构建与验证

Diff_Car使用本机ARM Compiler 5.06 update 5。关闭该目标编译前递归删除HEX的批处理，防止编译其他目标时清除已有固件；保留原有编译后HEX复制步骤。

主机测试命令：`python tests/test_eggy_profile.py`，需GCC在PATH。测试真实的车型初始化、差速逆运动学、停机函数和PWM输出函数，覆盖未配置、缺轮距、缺确认、完整配置以及原厂ADC回退。测试中的0.55 m只是合成输入，不是本底盘实测值。

Keil编译检查只证明代码能编译链接，不证明接线正确、屏幕已点亮或电机闭环稳定。本轮不自动烧录。

本轮验证（2026-10-12）：Diff_Car编译链接0错误、0警告；上述5组主机用例通过；HEX逐条记录长度/校验和及结束记录检查通过。链接报告为Flash 72456字节、SRAM 41368字节。HEX SHA256：`bb912da68fd9a3f5f2bf3c10ef3ef03bf3a4fc92112a0ee4386f2f152a3a77e9`。构建产物位于OBJ并按仓库规则忽略，需由当前源码重新生成。
