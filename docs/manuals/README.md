# C50C V4.3 开发与外围硬件手册

适用对象：C50C V4.3、STM32F407VET6，以及本仓库的 `Diff_Car` / `Eggy` 底盘适配。收录日期：2026-10-13。

这里集中提供开发所需的 PDF 和简短说明。每项资料列出用途、适用范围和文件页数；原理图及 WSDC2412D 手册沿用仓库已有文件。来源、文件大小和 SHA-256 见 [manifest.json](manifest.json)。

| 选择 Keil 编译目标、了解烧录 | [源码工程使用指南](../../源码工程使用指南.pdf)、[运动底盘开发手册](c50c/C50C_运动底盘开发手册_2026-06-30.pdf) |
