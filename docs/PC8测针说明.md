# PC8 固定高电平测针固件

Keil目标：`Diff_Car_PC8_Test`；输出：`OBJ/PC8_PinTest/Diff_Car_PC8_Test.hex`，编译后也复制到仓库根目录。

该目标定义 `CHASSIS_PC8_PIN_TEST=1`，把PC8从TIM8_CH3复用模式切为普通推挽GPIO并保持高电平。所有电机方向脚和PWM比较值保持0，输出就绪检查始终不成立，即使配置确认标志设为1也不允许正常电机控制。普通 `Diff_Car` 的测针宏默认为0，仍使用原有PWM功能。

测量前断开控制板与驱动板之间的排线。万用表使用直流电压档，黑表笔接C50C GND，红表笔测接口信号针脚。程序运行后PC8应约为3.3 V；电源3.3 V针脚本身也一直为高，不能仅凭电压把它误认作PC8。原理图预期PC8位于P2的第7脚，需用实物丝印及测量核对。不要用电流档跨接针脚。

该固件仅用于定位针脚；完成测量后重新编译、烧录普通 `Diff_Car` 恢复PWM控制。此次未自动烧录。
