# 右轮B通道短时测试

烧入 `Diff_Car_MotorB_Test.hex`。使用12 V电源，测试最低电压10 V；使能/急停检查保留。

上电等待5秒，B通道在0.5秒内升至50% PWM，保持约2秒，再用0.5秒降到0并停止。复位才会重新测试。OLED显示B TEST WAIT / RUN / BLOCKED / DONE。

B通道：PC8（TIM8_CH3，10 kHz）、PC0（IN1）、PE15（IN2）。运行方向IN1=1、IN2=0，A/C/D输出为0。请架空驱动轮，观察实际右轮转向。

实测B通道对应右轮，本测试方向同样为底盘后退。A/B单轮测试版保留诊断用途，正式控制的两路电机方向已翻转。
