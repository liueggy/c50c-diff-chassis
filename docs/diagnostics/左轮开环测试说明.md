# A通道低占空比单次运行测试

选择Keil目标 `Diff_Car_MotorA_Test`，烧录 `Diff_Car_MotorA_Test.hex`。A通道已实测对应左轮，输出为PC9/TIM8_CH4、PB13/PB12。该测试保留最初的诊断方向，实测为底盘后退方向。

## 运行顺序

- 主动轮架空后接回正确的驱动板排线。该固件不是PC8固定高电平固件。
- 上电后等待5秒，OLED显示 `A TEST WAIT`。请在等待期间确认使能开关和急停处于允许运行状态。
- 电压至少10 V（本次使用12 V电源）、硬件版本识别正常，且无软件停机、自检错误时：仅A通道PWM在半秒内升到50%，保持约2秒，半秒内降到0。OLED运行时显示 `A TEST RUN`。
- 约第8秒结束，显示 `A TEST DONE`。不重复运行；重新复位才会开始下一次测试。
- 急停、欠压或软件停机在运行窗口内触发时，取消本次测试，显示 `A TEST BLOCKED`；恢复使能不会自动续转。

## 实现和边界

使用开环PWM，不依赖编码器方向或PI闭环。PWM频率仍为10 kHz，占空比上限为8400/16800=50%。B/C/D输出为0，未用通道的方向输入也为0。正常 `Diff_Car` 的配置确认门控保留，不因诊断目标解除。

低占空比不等于固定低转速。若没有转动，先记录OLED状态、使能、供电和驱动板指示灯；低占空比不足以克服负载、插座/针序不符等也可能造成无动作，不能直接据此判断引脚错。若右轮转动，则当前A通道实际上接到了右轮。下一次根据观察结果明确调整，避免随意尝试不同GPIO。

该测试目标跳过常规遥控/串口运动控制、速度PI、自动回充运动和参数保存。相关原厂静态函数因此会产生8条“未引用函数”的编译警告；它们不参与测试输出。本目标已由用户烧录并确认左轮能转；代理没有自动烧录。

完成测试后烧回普通 `Diff_Car.hex`。诊断目标以外的 `CHASSIS_MOTOR_A_PROBE` 默认是0，并禁止与PC8固定高电平测试同时开启。

本次电压门槛10 V仅用于短时台架测试，不作为12 V电池的放电保护设定。12 V、50% PWM是约12 V脉冲的占空比调节，理想平均值约6 V，不是稳压6 V输出。急停/使能输入检查仍保留。
