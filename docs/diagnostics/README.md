# 诊断与历史测试入口

日常开发和串口运行选择 **Diff_Car**，烧录重新编译的 `Diff_Car.hex`。下列独立目标仅用于诊断，测试固件不能作为正式串口控制固件。

| Keil目标 | 用途与行为 | 说明 |
|---|---|---|
| Diff_Car_PC8_Test | PC8固定高电平；禁用电机输出，测量时断开驱动排线 | [引脚测量](PC8测针说明.md) |
| Diff_Car_MotorA_Test | 左轮A开环；5秒等待、最高50% PWM、约8秒停止；诊断方向为后退 | [左轮测试](左轮开环测试说明.md) |
| Diff_Car_MotorB_Test | 右轮B开环；与A测试同样时序和占空比；诊断方向为后退 | [右轮测试](右轮开环测试说明.md) |
| Diff_Car_ClosedLoop_Test | 两轮前进80 mm/s；5秒等待、运行5秒、约10秒停止 | [闭环测试](两轮低速闭环测试说明.md) |

已由用户确认：A左/B右、电机方向、编码器前进反馈为正；80 mm/s闭环运行、定时停止及使能OFF停机通过。

单轮和闭环测试使用10 V短时台架门槛；正式固件按集中配置采用9.5 V停机门槛。测试应架空驱动轮；固定PWM不代表固定转速。原厂其他车型目标保留兼容用途。

根目录和OBJ中的HEX是被Git忽略的本地生成文件；文件名相同不保证版本相同，烧录前先选择目标重新编译。不要把历史固件作为源码状态的依据。
